# Mesob House Web Application

**Project Overview**
A responsive web application designed for **Mesob House**, delivering an authentic Ethiopian culinary and digital hospitality experience. Built with a pixel-perfect design language derived directly from Desktop and Mobile Figma specifications.

---

**Key Features & Highlights**

* **Authentic Ethiopian Aesthetic**: Rich earth-tone palettes (`#fdf8f4`, `#8b261d`), serif typography, and custom cultural elements.
* **Dual-Viewport Architecture**: Fully responsive web design with dedicated desktop layouts alongside native-like mobile interfaces.
* **High-Fidelity Auth & Onboarding**: Registration and login workflows incorporating localized Ethiopian phone verification (`+251`).
* **Integrated Trust & Loyalty Systems**: Custom banner badges highlighting member perks (Tej/Buna welcome gifts, Communal Gursha loyalty points).

---

**Tech Stack**

* **Frontend**: React.js, React Router DOM v6, Custom CSS Modules
* **Build Tooling**: Vite
* **Design**: Figma (Desktop & Mobile viewports)
